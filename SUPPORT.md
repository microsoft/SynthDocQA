# Support

This project uses community support through this repository's GitHub Issues. Search open and closed issues before opening a new one. Use an issue for setup questions, reproducible bugs, or feature requests.

Include the package/Python version, operating system, command used, expected behavior, and a minimal sanitized reproduction. Redact credentials, endpoints that identify private deployments, private documents, generated result payloads, and sensitive log content. State whether a failure occurs before or during a configured service call.

Support covers the released generator and execution scripts, not validation of every generated answer, hosted service availability, or deployment administration. For service/account issues, use your provider's support channel. Community replies are best-effort; there is no guaranteed response time or commercial support commitment.

Do not report security vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md). For conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
